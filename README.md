# suspect-site

Den offentlige side for appen **Suspect: Word Bluff**: support og privatlivspolitik.

Filerne her er genereret. Ret dem ikke i hånden. Kilden er `docs/PRIVACY.md` i app-repoet,
og siden bygges med:

```sh
npm run build:site
npm run publish:site -- ../suspect-site
```

Derefter commit og push her. GitHub Pages serverer `main` fra roden.

- Support: <https://asbjornfa.github.io/suspect-site/>
- Privatliv: <https://asbjornfa.github.io/suspect-site/privatliv.html>
